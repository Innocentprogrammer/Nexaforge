# Technical Requirements

Performance:

- Lighthouse Score ≥ 90
- First Contentful Paint < 2 s
- Largest Contentful Paint < 2.5 s

Accessibility:

- WCAG 2.2 AA compliance
- Keyboard navigation
- Screen reader compatibility

Security:

- HTTPS
- Content Security Policy
- Rate limiting for forms
- CAPTCHA where appropriate
